Convertir PDF

Renombra los campos AcroForm de un PDF "feo" (Text3, Check Box4) a nombres semanticos (lugar, primer_apellido) usando el Excel como diccionario.

Genera JSONs en formato Lovable a partir de la Matriz Excel + PDFs. Opcionalmente enriquece un JSON Lovable existente.
