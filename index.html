Instructivo rápido (click para expandir)
  1. Preparar la Matriz Excel: Agregar una columna Código Formulario que identifique a qué formulario pertenece cada fila. El valor debe coincidir con el nombre del archivo PDF (sin la extensión .pdf). Las filas con valor vacío o "Todos" se incluyen en todos los formularios.
  2. Subir la Matriz: Hacer click o arrastrar el archivo .xlsx en el slot "Matriz Excel".
  3. (Opcional) JSON Lovable: Si ya tenés un JSON generado por Lovable (escaneando el PDF), subilo para usar el modo enriquecimiento: el JSON Lovable provee las coordenadas y campos del PDF, y el Excel agrega reglas, validaciones, opciones y prefillKeys. El código de formulario se extrae de _sourcePdf.fileName.
  4. Subir los PDFs: Arrastrar uno o más archivos .pdf a la zona de PDFs. El nombre del archivo (ej: 1009052.pdf) se usa como código para vincular con la columna Código Formulario de la matriz.
  5. (Opcional) Catálogos: Si tenés un Excel de catálogos, subilo para enriquecer los options de combos/selects.
  6. (Opcional) JSON cliente: Subilo para validar que los prefillKey existan en la estructura del cliente.
  7. Generar: Click en "Generar JSON" para producir un JSON Lovable por cada PDF o JSON Lovable cargado.
  8. Descargar: Descargá cada JSON individualmente o todos juntos en ZIP.
